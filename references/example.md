# 完整实例：A 公司 5-8 月收入看板（脱敏加密）

> 本例全程使用化名，不涉及任何真实公司名与客户信息。真实数据请放在本地，勿写入本技能文档。

## 原始数据（输入格式示例）

`income_202605_08.json`，195 条，字段：

```json
{"n":"学员姓名","src":"老生","c":"篮球初级班","a":2999.0,"p":"支付宝",
 "se":18,"f":0,"signer":"签单人甲","teacher":"授课老师甲","d":"2026-05-31"}
```

## 命令

```bash
PY="C:/Users/jiang/.workbuddy/binaries/python/versions/3.13.12/python.exe"
SK="C:/Users/jiang/.workbuddy/skills/sales-viz-secure"

# 1. 脱敏（L2：学员编号化，授课老师化名，科目转兴趣课，签单人留真名）
#    注意：这是教育培训行业，必须显式 --industry education；默认 generic 不会做科目/支付改写
"$PY" "$SK/scripts/anonymize.py" \
  -i income_202605_08.json \
  -o data_masked.json \
  --industry education --level L2 --mapping-out mapping.json

# 2. 生成加密看板（⚠ 标题用化名/代号，不要写真实公司名；锁屏标题默认不含公司名）
"$PY" "$SK/scripts/build_dashboard.py" \
  -i data_masked.json -o 销售看板_加密版.html \
  -p "你的密码" \
  --title "A公司 · 2026年5-8月销售分析" \
  --subtitle "195笔签单 · 数据已脱敏" \
  --qty-label "课次" --lock-title "销售数据看板"
```

## 验证脱敏是否到位

```bash
# 标题/公司名/真实姓名/原科目 都应查不到（0 处）
grep -c "真实公司名\|围棋\|英语\|签单人真名\|客户真名" 销售看板_加密版.html   # 应全部为 0
```

生成后必须跑这一步。若出现 >0，说明有明文泄漏（多半是标题里写了敏感词，
或误用了 `--cdn` 之外的自定义模板）。

## 公司名脱敏

看板标题（`--title`）和锁屏标题（`--lock-title`）都可能被人看到：
- **锁屏标题**（明文，唯一可见文字）默认就是"销售数据看板"，不要改成公司名。
- **看板内标题**虽在密文里，但解密后可见，对外分享时请用 **A公司 / XX公司 / 某公司** 等化名，
  不要写真实公司全称。本例统一用「A公司」。

## 常见问题

**Q: 提示"未识别到日期或金额列"**
用 `--map` 手动指定：`--map "成交日期=d" --map "实收金额=a" --map "学员姓名=n"`

**Q: 多个月分开的 Excel 怎么合并**
`-i 202605.xlsx 202606.xlsx 202607.xlsx --dedup`

**Q: 下个月更新数据，怎么让学员编号不变**
用 `--mapping mapping.json`（读入并原地更新），老客户沿用旧编号，新客户接着编。

**Q: 授课老师 / 科目要不要也匿掉**
默认已做：老师→李老师/王老师…化名，科目→篮球/钢琴等兴趣课。
如需保留真名：`--keep-teacher`；科目保留原名：`--no-subject-remap`。

**Q: 忘了密码**
无法找回，重新用新密码生成一份即可（源数据还在）。

**Q: 手机打开白屏**
多半是用了 `--cdn` 且手机没网。改成默认的内嵌模式重新生成。

## 其他行业 / 其他公司（通用版）示例

> 核心卖点：**别的公司拿表来，不加任何参数就不会被改坏**——因为默认 `generic` 不碰科目名、不碰支付方式。
> 只有你们培训行业才需要显式 `--industry education`。

假设一家餐饮连锁的表头是 `成交日期 / 实收金额 / 商品 / 客户名 / 店员 / 来源 / 收款方式 / 门店`，
直接跑（**无需任何行业参数**）：

```bash
# 通用行业：商品名原样保留，店员化名，支付按 微信/支付宝/银行卡/现金/其他 归并
"$PY" "$SK/scripts/anonymize.py" \
  -i 餐饮流水.xlsx -o 餐饮_masked.json --level L2 --mapping-out 餐饮_mapping.json
```

若列名特别冷门识别不了，用 `--map` 指定；想保留原始支付写法（不做归并）加 `--no-payment-remap`。

各行业差异一览：

| 行业 | 怎么跑 | 科目/商品 | 支付 | 员工标签 |
|---|---|---|---|---|
| 通用（默认） | 直接跑 | 原样 | 原样 | 服务人员A |
| 教育培训 | `--industry education` | K12→兴趣课 | 微信/支付宝/银行卡/现金 | 李老师… |
| 餐饮零售 | `--industry retail` | 原样 | 含「其他」兜底 | 店员A |
| 医疗诊所 | `--industry clinic` | 原样 | 含医保 | 医师A |
| B2B制造 | `--industry b2b` | 原样 | 含月结/信用证 | 业务员A |

要加新行业：复制 `references/industry/generic.json` 改 `dim_labels`/`payment_remap`/`customer_prefix` 等字段即可，无需改代码。
