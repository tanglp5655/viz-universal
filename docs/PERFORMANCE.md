# 性能基线（PERFORMANCE）

压测环境：win32 / Python 3.13.14
压测方式：`python scripts/benchmark.py 100000`（虚构数据，固定随机种子可复现）

| 阶段 | 耗时 | 说明 |
|---|---|---|
| 数据生成 | 即时 | 100000 行虚构明细 |
| 脱敏 L2 | 26.4s | 列语义识别 + 编号化 |
| 生成（免密直开） | 14.9s | Chart.js/ECharts/地图内嵌，免加密 |
| 生成（加密） | 30.8s | 含 12 万次密钥迭代 + CTR 加密 |

产物大小：
- 原始 JSON：21.2 MB
- 脱敏 JSON：21.2 MB
- 免密看板：19.9 MB（图表库+地图内嵌占大头，与行数关系小）
- 加密看板：23.4 MB

## 大数据前端降级策略（已内置）
- 明细表：分页加载（初始 60 行，点「加载更多」+100），不一次性渲染全量。
- 走势图：按月聚合为少量点；维度排行取 Top 60（可加载更多）。
- 地图：按省/市/区聚合，颜色深浅 = 聚合值。
- 演示模式：`--sample N` 随机采样 N 条生成（固定种子可复现），适合超大文件快速出图。

## 说明
- 加密耗时主要来自 12 万次密钥迭代（固定 ~1-3s）与全量 XOR/Base64（线性）。
- 若需更快：内部联调可用 `--iter 1000`；对外发布请保持默认。
